# project-evolve

供 Codex 与 Claude Code 使用的个人项目演进 skill。你指定一个或多个仓库和长期目标，它先分析现状，再按你确认的方向做实验、验证和阶段汇报。

## 个人安装

将本仓库的 `skills/project-evolve` 整个目录复制到对应位置。更新时从同一份源文件同步。

| 客户端 | 个人目录 | 对话中调用 |
| --- | --- | --- |
| Codex | `~/.agents/skills/project-evolve/` | `$project-evolve` |
| Claude Code | `~/.claude/skills/project-evolve/` | `/project-evolve` |

新建一个独立的任务目录，从里面启动客户端，并按客户端的工作区权限加入所需业务仓库。用上述命令开始，附上目标、仓库路径、可改范围及首次最晚汇报时间。例如：

> 分析首次比价的等待体验，提出一个优先方向。客户端和服务端路径见下方，首次调查可读取两个仓库。今天北京时间 17:00 前汇报。

每个任务自己的 `EVOLUTION.md` 记录授权、汇报时间、实验与进度。切换客户端时，先结束原运行，在同一任务目录调用 skill 并说“继续”。任务目录及业务仓库无需放入本 skill 仓库。

第一版只在活跃会话中推进。中断后可以恢复，逾期先补报。每个演进分支默认本地提交，是否上线由你决定。
